# V10 Training Guide

## What is V10 Trainable?

V10 is a poker agent that learns per-bucket hand strength adjustments through training. Unlike V6 which has static learned thresholds, V10 optimizes each of 40 hand strength buckets independently.

---

## Quick Start (3 Steps)

### Step 1: Train V10
```bash
python train_v10_agent.py 30
```

This will:
- Run 30 games vs each of 8 opponent types = 240 total training games
- Track which hand strength buckets win/lose
- Compute optimal adjustments for each bucket
- Save results to:
  - `v10_trained_buckets.json` - Per-bucket adjustments (loaded on startup)
  - `v10_training_report.json` - Detailed statistics

**Training time:** ~8-12 minutes for 240 games

### Step 2: Test V10 vs V6
```bash
python test_v10_vs_v6.py
```

This runs 20 games per opponent (100 total) and shows performance comparison.

### Step 3: Review Results
```bash
cat v10_training_report.json
cat v10_trained_buckets.json
```

## Architecture

### Hand Abstraction (40 Buckets)

V10 divides hand strength into 40 equal buckets:
- Bucket 0: 0.0-0.025 (very weak hands)
- Bucket 1: 0.025-0.05
- ...
- Bucket 39: 0.975-1.0 (very strong hands)

Each bucket gets its own threshold adjustment based on training results.

### Per-Bucket Learning

During training, V10 tracks:
```
bucket_stats[bucket] = {
    "wins": count,
    "losses": count,
    "win_rate": wins / (wins + losses),
    "adjustment": computed_adjustment
}
```

Adjustments are computed as:
- Win rate > 65%: Lower thresholds (be more aggressive) → adjustment = -0.04
- Win rate 55-65%: Slightly lower → adjustment = -0.02
- Win rate 45-55%: No change → adjustment = 0.0
- Win rate 35-45%: Slightly higher → adjustment = +0.02
- Win rate < 35%: Raise thresholds (be more conservative) → adjustment = +0.04

### Files

**monte_carlo_v10_trainable.py**
- The agent code
- Loads `v10_trained_buckets.json` on startup
- During play, uses learned adjustments or adapts from recent 40 rounds

**train_v10_agent.py**
- Training pipeline
- Runs games against 8 opponent types
- Accumulates bucket statistics
- Saves learned adjustments

**v10_trained_buckets.json** (Generated by training)
```json
{
  "bucket_adjustments": {
    "0": 0.02,    // Weak hands: play tighter
    "1": 0.01,
    ...
    "39": -0.04   // Strong hands: play looser
  },
  "bucket_stats": { /* detailed per-bucket stats */ },
  "training_timestamp": "2026-05-03T..."
}
```

## How V10 Uses Trained Buckets

### Initialization
```python
agent = MonteCarloV10Trainable()
# Loads: trained_weights.json (base thresholds)
# Loads: v10_trained_buckets.json (bucket adjustments)
```

### During Play
For each decision:
1. Evaluate hand strength → classify into bucket (0-39)
2. Get base threshold from street (preflop/flop/turn/river)
3. Apply learned adjustment for that bucket
4. Make decision based on adjusted threshold

### Adaptive Learning
If not enough training data (`v10_trained_buckets.json` doesn't exist):
- V10 tracks last 40 rounds of play
- Adjusts thresholds based on recent bucket performance
- Falls back to base V6 thresholds if insufficient data

### Test Against Specific Opponent
Create `test_v10_vs_opponent.py`:
```python
from monte_carlo_v10_trainable import MonteCarloV10Trainable
from opponent_types import get_opponent_by_type
from pypokerengine.api.game import setup_config, start_poker

agent = MonteCarloV10Trainable()
opponent = get_opponent_by_type("TightAggressive")

wins = 0
for _ in range(20):
    config = setup_config(max_round=10, initial_stack=1000, small_blind_amount=10)
    config.register_player(name="Agent", algorithm=agent)
    config.register_player(name="Opp", algorithm=opponent)
    result = start_poker(config, verbose=0)
    if result["players"][0]["stack"] > result["players"][1]["stack"]:
        wins += 1

print(f"Win rate vs TightAggressive: {wins}/20 ({wins/20:.1%})")
```

## Troubleshooting

### "FileNotFoundError: v10_trained_buckets.json"
- This is normal if you haven't trained yet
- V10 will work using just base thresholds + recent 40 rounds
- Run `python train_v10_agent.py 30` to train

### "Low performance after training"
- Check v10_training_report.json for bucket performance
- May need more training games (try 50 instead of 30)
- Or try increasing adjustment magnitude in _apply_bucket_adjustment()

### "Performance worse than V6"
- V10 may be overfitting to training opponents
- Try reducing the adjustment magnitude (-0.04 to -0.02, etc.)
- Or increase learning window from 40 to 60+ rounds

## Advanced: Fine-tuning Bucket Adjustments

If you want to adjust the adjustment magnitude, modify `monte_carlo_v10_trainable.py`:

```python
def _apply_bucket_adjustment(self, raise_threshold, call_threshold, hand_bucket):
    # Current values: ±0.04 for extreme win rates
    # To be more conservative:
    # if bucket_win_rate > 0.65:
    #     adjustment = -0.02  # Instead of -0.04
    # elif bucket_win_rate > 0.55:
    #     adjustment = -0.01  # Instead of -0.02
```

Or adjust the win rate thresholds:
```python
# Current: 0.65, 0.55, 0.45, 0.35
# More aggressive: 0.60, 0.50, 0.40, 0.30
# More conservative: 0.70, 0.60, 0.50, 0.40
```

Then re-train to see if performance improves.
